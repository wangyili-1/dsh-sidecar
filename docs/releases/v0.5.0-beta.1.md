# v0.5.0-beta.1 — 多模型协作与网页人工交接

这次预发布让 DSH 主会话通过原生工具分派子任务，在同一侧栏查看成员、任务状态和结果。已有的网页标签、独立侧聊及可拖动分屏继续保留，默认网页改为百度首页。

## 新增功能

- **API 协作**：支持 Chat Completions、Responses、Images 和 Claude Messages 基础协议；提供 GLM、Qwen、OpenAI Image、Claude 停用预设，也可配置兼容中转接口。
- **网页人工交接**：DeepSeek、豆包、Qwen、Kimi 官网预设，复制提示词、手动在官网提问、粘贴回答并保存。待办可跨服务重启保留，结果标注“用户粘贴”。
- **本机模型**：Ollama 等回环地址兼容接口可不填写 Key；需要自行安装并启动服务、下载模型和启用成员。
- **主控工具**：列出成员、分派、查看、有限等待、取消；默认最多并行执行 3 项 API 任务，结果保存到所属主会话工作区。
- **更直接的网页入口**：打开侧栏或新建网页即显示百度；右上只留侧栏开关，功能统一放在标签栏 ＋。
- **7 组可复制提示词**：方案与边界审查、Bug 交叉验证、网页交接与恢复、本地文本整理、产品插画、已有结果整合和小调用量试跑。

## 开始使用

[提示词模板](https://github.com/wangyili-1/dsh-sidecar/blob/v0.5.0-beta.1/docs/PROMPTS.md) · [协作配置](https://github.com/wangyili-1/dsh-sidecar/blob/v0.5.0-beta.1/docs/MULTI_AGENT.md) · [网页与本地资源](https://github.com/wangyili-1/dsh-sidecar/blob/v0.5.0-beta.1/docs/FREE_RESOURCES.md)

适配 **DSH 0.1.2-rc.1 / Node.js 22+**。首次安装可用下面的源码方式：

```powershell
git clone --branch v0.5.0-beta.1 https://github.com/wangyili-1/dsh-sidecar.git
cd dsh-sidecar
npm ci
npm run build
npm run doctor
npm run install:dsh -- --workspace "C:\path\to\your-project"
```

把示例工作区路径改为自己的项目。从 v0.4.1 升级时，先保存草稿并停止任务，再更新原插件目录、安装依赖和构建，最后重启 DSH 服务加载协作后端。仅关闭浏览器窗口可能不会停止服务。

打开 **侧栏 → ＋ → 协作任务 → 配置协作成员**。安装包不会携带开发者的成员、密钥、任务记录或本地模型。

## 下载内容

- `dsh-sidecar-0.5.0-beta.1.tgz`：包含构建后的 `lib/`；解压到长期保留的位置，执行 `npm install --omit=dev`，再运行诊断和安装命令。
- `dsh-sidecar-v0.5.0-beta.1-source.zip`：对应发布提交的源码，需 `npm ci` 和构建。
- `SHA256SUMS.txt`：以上两个文件的校验值。

## 验证与边界

本机完整测试 **205 项通过、0 失败、0 跳过**。真实 DSH 界面已验证网页任务交接、回答回填与文件保存，以及默认百度首页；网页回答验收使用明确标注的本地测试文字。远端测试状态见 [GitHub Actions](https://github.com/wangyili-1/dsh-sidecar/actions/workflows/test.yml)，详细范围见 [VALIDATION.md](https://github.com/wangyili-1/dsh-sidecar/blob/v0.5.0-beta.1/VALIDATION.md)。

**本版是 Beta：**尚未用真实供应商账号验证鉴权、在线推理与生图。网页入口需要人工操作，不提供免费自动 API；网页免费权益与 API 额度分别计算，DSH 主模型继续使用原有配置。外部 API 成员目前没有独立的终端、浏览器或本地代码执行循环。WorkBuddy OAuth / ACP 专用桥接尚未实现。

稳定版 [v0.4.1](https://github.com/wangyili-1/dsh-sidecar/releases/tag/v0.4.1) 继续保留；此预发布不替换稳定版 Latest。

## English

This beta adds DSH-led task delegation, configurable text/image API workers, manual website handoffs, no-key local Ollama support, seven copyable Chinese prompt templates, and Baidu as the default browser page. Website tasks require manual submission and pasted answers. Real provider authentication, inference and image generation have not been validated; protocol tests and local UI handoffs have. Stable v0.4.1 remains available.
